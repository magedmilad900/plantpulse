# PlantPulse — Python Dashboard

واجهة Dashboard داكنة تفاعلية مبنية بـ Python وStreamlit، ببيانات تجريبية محلية لستة أصول صناعية.

## التشغيل

```bash
python -m venv .venv
# Windows
.venv\\Scripts\\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```

بعد التشغيل افتح الرابط الذي سيظهر في الطرفية، غالبًا:

```text
http://localhost:8501
```

كل البيانات تجريبية وليست توقعات صناعية فعلية.
